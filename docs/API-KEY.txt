DeepSeek Harness —— 第一次使用必读
=================================

这个软件装好后第一步是配置你自己的 DeepSeek API Key。
安装包里不含任何 Key，每个使用者用自己的账号，互不影响。

一、启动
--------
双击开始菜单或桌面上的 "DeepSeek Harness" 图标。
它会启动本地服务、自动挑一个空闲端口，并用默认浏览器打开界面。
本机地址只监听 127.0.0.1，不对局域网开放，也不需要管理员权限。

二、配置 API Key（只需一次）
-----------------------------
1. 在打开的界面里进入：设置（Settings）→ 模型（Models）
2. 第一次启动会自动弹出引导，按提示填入你的 DeepSeek API Key（形如 sk-...）
3. 点应用 / 保存。Key 会保存到本机：
     %USERPROFILE%\.dsh\.credentials.yaml
   写入后立即生效，不需要重启程序。
4. 左侧模型行会出现绿色圆点，表示该凭据已配置成功。

如果你还没有 Key：到 DeepSeek 开放平台创建一个（https://platform.deepseek.com）。
界面里的 Key 输入框是只写的，保存后不会回显，也不会写进 settings.yaml。

不想把 Key 存文件的话，也可以先设置环境变量再用启动器：
    setx DEEPSEEK_API_KEY "sk-你的key"
环境变量的优先级高于文件，重启命令行/程序后生效。

三、数据都在哪
--------------
默认目录：%USERPROFILE%\.dsh
  .credentials.yaml  你的 API Key
  settings.yaml      界面设置
  profiles\          运行配置（首次启动自动生成）
  sessions\          历史会话
  logs\              从快捷方式启动时的运行日志

想让数据跟着安装目录走（例如放到 U 盘）：设置环境变量
    setx DSH_PORTABLE 1
也可以完全自定义：setx DSH_HOME "D:\我的目录"

四、出问题时
------------
1. 用"DeepSeek Harness（终端）"图标启动，可以看到完整实时输出。
2. 运行 launchers\dsh-diagnose.ps1，它会打印版本、路径、端口、最近日志。
3. 快捷方式启动失败时会弹出提示框，里面写着这次运行的日志文件路径。

五、卸载
--------
通过"设置 → 应用 → 已安装的应用"卸载。
卸载默认**保留** %USERPROFILE%\.dsh（你的 Key 和历史会话），
卸载时会询问是否一并删除。
